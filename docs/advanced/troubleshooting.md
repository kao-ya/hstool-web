# 常见报错排查

## 打开一直是骨架屏 / 卡牌库不出现

先看 **设置 → 日志**，里面按顺序记录了：

```
[load] fetch data/... → 200 / 404 / 超时
[load] 索引构建 36,022 张，用时 xxx ms
[img] 卡图回退 cn → en → placeholder
```

- 卡在第一条 → 数据文件 404 或网络被拦（公司代理、广告插件、DNS）
- 卡在第二条 → 设备内存不足，尝试开启「紧凑布局」并缩小窗口
- 有数据但网格空白 → 大概率是渲染报错，打开控制台看第一条红色错误

## 整屏都是占位卡背

1. 图床不可达：`art.hearthstonejson.com` 被墙或被代理拦
2. `api/card-img` 转发函数没部署 / 被禁用
3. 浏览器插件拦第三方图片

逐个排除：直接访问一张图床链接能打开 → 是第 2、3 条；打不开 → 是第 1 条。

## 卡组代码解不出来

- 复制时被换行/空格污染 → 先粘进记事本再去掉空白
- 卡组里包含数据里没有的卡（新版本刚上线）→ 等卡库更新
- 官方格式文本里卡名有异体字 → 用短码导入，别用文本

## 切换英雄后卡组没了

**设计如此**：切换英雄会清空当前卡组。先「生成代码」保存再换。

## 点加入没有反应 / 提示超限

看提示条的具体文案：30 张上限、传说 1 张、其余 2 张、互斥卡冲突。互斥冲突时卡库上那张卡是红色偏色，鼠标悬停会说明跟哪张卡冲突。

## 详情页卡图不跟随鼠标

**设置 → 功能 → 详情页 3D 效果** 是否被关了；另外「减弱动效」开着时部分动效也会被压掉。

## 分割线/边框不见了

**设置 → 控件 → 去边框去线条** 打开时会隐藏所有静态描边与分隔线，包含设置面板里那些细线；开关轨道保留描边（否则控件看不见）。

## 导出的海报图很慢

海报是把每张卡的缩略图拉下来再画进 canvas，第一次生成受图床速度影响；同一批卡之后走浏览器缓存会快很多。

## 还是不行

带上 **设置 → 日志** 里的内容和浏览器控制台的报错，去 [GitHub Issues](https://github.com/kao-ya/hstool-web/issues) 提一条。
