# 卡牌详情

点击卡库里的任意一张卡，右侧会弹出详情面板。

## 包含的信息

- **卡面大图**（可切异画，见下）
- **属性**：法力、攻击、生命、耐久（武器才有）
- **描述**：卡牌文本，关键词高亮
- **杂项**：系列、稀有度、类型、种族/派系、画家、平衡性变动等
- **归属**：奇闻卡的附属卡、乐队/定制模式的归属关系
- **风味文本**（flavor text）

## 鼠标 3D 倾斜

鼠标在卡面上移动时，卡图会跟随指针做轻微倾斜，有立体感。不想要可以去 **设置 → 功能 → 详情页 3D 效果** 关掉，关掉的瞬间卡图会立刻扶正，不用等鼠标移开。

## 异画（签名卡图）

部分卡牌有官方签名版卡图。详情页标题旁会多一个「看异画」按钮：

- 点一下切到签名卡图，再点切回原图
- 只有确实存在签名卡的卡才会出现这个按钮（工具会先探测一次，探测结果缓存在本地）
- 探测失败不影响原图显示

## 属性用图片 / 用文字

**设置 → 功能 → 属性用图片**：

- **开**（默认）：法力用水晶、攻击用剑、生命用血滴图标做底图
- **关**：退回老式小卡片——灰底细边，标签在上、数值在下

两种模式的布局尺寸不同，切换时不会留下错位。

## 关键词与提示

卡牌文本里的关键词（战吼、亡语、吸血、圣盾……）在描述里会以高亮样式出现，便于快速扫读。
