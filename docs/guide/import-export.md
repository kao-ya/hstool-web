# 导入与导出

## 导入

切到「解码」标签页，把内容粘进输入框，会自动识别格式：

### ① 官方卡组代码（短码）

形如 `AAECAZ8FBvboA6HiA4f1A8igBJfvBI21BA/7A...` 的一串 Base64。解码后得到英雄、所有卡牌与份数，并可以直接送进组卡器。

### ② 官方格式文本

在游戏里用「复制卡组」得到的是这种多行文本：

```
# 2x (1) 圣光闪现
# 1x (2) 凯瑞尔·罗姆
AAECAZ8FBvboA6HiA4...
```

直接整段粘进去即可。工具会**先尝试当短码解**，失败则按行解析 `# Nx (费用) 卡名`，卡名支持中文；两种都不成立才报错。

> 卡名解析失败会提示具体是哪一行，通常是版本太旧（数据里还没有这张卡）或卡名有异体字。

### ③ 从组卡器回填

组卡器右上角有「导出到解码页」，会把当前卡组直接生成短码填进解码页输入框，省去手抄。

## 导出

| 方式 | 说明 |
| --- | --- |
| 生成短码 | 官方 deckstring，可粘回游戏或发给别人 |
| 复制链接 | 卡组内容编码进链接，打开即还原 |
| 导出海报图 | 生成一张带英雄、曲线、粉尘、卡表的图片 |

编码时卡牌按 `dbfId` 升序排序，所以**同一个卡组每次生成的短码完全一致**——方便对比与去重。

## 关于 deckstring 格式

想了解版本号、格式位、单张/双张/多张块是怎么编的，见 [卡组代码（deckstring）](/advanced/deckstring)。
