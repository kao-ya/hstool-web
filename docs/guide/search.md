# 搜索与筛选

## 搜索框能搜什么

- **卡牌名称**（中文 / 英文）
- **卡牌描述文本**（关键词也能命中，比如「战吼」「吸血」）
- **卡牌 ID**（如 `EX1_001`）
- **dbfId 前缀**

输入即搜，不需要回车。

## 8 个筛选维度

职业、类型、稀有度、随从种族、法术派系、系列、费用、收藏状态。

组合规则：

- **同一维度多选 = 并集**（职业选「法师 + 牧师」→ 职业是法师**或**牧师）
- **不同维度 = 交集**（职业选法师 + 类型选法术 → 法师**的**法术）

## 已选条件

选中的条件会以标签形式排在上方，可以：

- **单点移除**：点标签上的 ×
- **一键清空**：「清空」按钮把所有条件与搜索词一起复位

## 结果与分页

- 每页 200 张，底部翻页，也可直接看总页数（全库 36,022 张 = 181 页）
- 卡图**懒加载**：只加载屏幕上看得见的那一批，滚动到哪加载到哪，所以翻页不用等全部图片
- 未加载的位置预留了卡面比例，不会边滚边跳

## 卡图加载不出来怎么办

三级回退：中文卡图 → 英文卡图 → 本地占位卡背。如果整屏都是占位卡背，多半是：

1. 网络访问不了卡图源（`art.hearthstonejson.com`），检查代理/网络
2. 浏览器拦了第三方图片（某些隐私插件）
3. 特殊类型的内部对象（附魔、按钮、拖动）**本来就没有卡图**，直接显示占位卡背是正常行为

详见 [常见报错排查](/advanced/troubleshooting)。
