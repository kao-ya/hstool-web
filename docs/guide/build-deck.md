# 组一套卡组

## 1. 先选英雄

页面顶部是英雄选择器，11 个基础职业排成一行，点一下即可切换。**切换英雄会清空当前卡组**，所以先把手里正在攒的卡组导出成代码再换。

## 2. 从卡库挑卡

左侧是卡牌库，右侧是卡组。挑卡有三种方式：

- **点击**卡牌 → 加入一张
- **拖拽**卡牌到右侧卡组区 → 加入一张
- 在卡组里点 **+ / −** → 调整份数

卡库每页 200 张，底部翻页；同一个筛选条件下页面位置会保留。

## 3. 看懂卡库上的两种标记

卡库会实时反映卡组状态，用两种视觉效果提示：

| 标记 | 含义 |
| --- | --- |
| 红色偏色 | 与卡组里已有的卡**互斥**，不能同时携带（例如「雷纳索尔王子」与「裂魂者阿扎莉娜」这类同尺寸替换卡） |
| 灰黑偏色 | 这张卡的携带份数**已经用满**：传说卡带 1 张即灰，其余带满 2 张变灰 |

把鼠标停在卡上会有提示说明具体原因（「与卡组中的「裂魂者阿扎莉娜」互斥，不能同时携带」/「传说卡只能带 1 张，已满」）。两种标记都只是提示，不影响你继续点——但构筑规则会在超限时拦住。

## 4. 构筑规则怎么校验

- 卡组上限 **30 张**
- **传说**卡每种 1 张，其余每种 2 张
- 同尺寸互斥卡不能并存
- 部分卡牌有归属关系（附属卡、乐队/定制模式），移除主卡时会一起清掉，不留孤儿卡

超限时会有提示条，不会静默失败。

## 5. 看统计

组卡器底部实时显示：

- **总粉尘**：按稀有度换算合成所需奥术之尘
- **法力曲线**：按费用分桶的柱状图，随增删卡即时变化
- **卡牌数量**：当前张数 / 30
