# 这是什么

HsTool 是一个**完全在浏览器里运行**的炉石传说卡组工具：打开网页就能组卡、解析卡组代码、导出海报，没有账号、没有服务器、没有上传下载。

## 它能做什么

| 能力 | 说明 |
| --- | --- |
| 组卡器 | 从 36,022 张卡里筛选、加入卡组，自动校验构筑规则，实时统计粉尘与法力曲线 |
| 卡组代码 | 官方 deckstring 的双向转换：短码 ↔ 卡组 |
| 官方文本导入 | 直接粘贴游戏里「复制卡组」得到的整段文本，自动识别并降级解析 |
| 卡牌详情 | 卡面大图、卡牌描述、关键词、杂项数据、异画切换 |
| 卡组海报 | 一键导出图片，或生成分享链接 |
| 12+ 项设置 | 动效、透明度、布局、属性显示方式，全部本地保存 |

## 它是怎么工作的

没有任何后端。站点启动时把整份卡牌数据库下载到浏览器（压缩后约 11 MB，之后走缓存），此后所有查询、编码、渲染都在本地内存里完成：

```
卡牌数据库 (JSON, 一次加载)
        │
        ├── 索引与筛选 ──→ 卡牌库网格（分页 200 张）
        ├── 卡组数据   ──→ 组卡器（校验 / 粉尘 / 曲线）
        └── 编解码器   ──→ deckstring ↔ 卡组
```

好处是：**不会因为服务器挂了而用不了，也不会有任何卡组数据离开你的浏览器**。代价是首次打开要下载一次数据库（做了骨架屏与分阶段加载，先进界面再补数据）。
