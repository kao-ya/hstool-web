# 更新日志

## 2025-11 近期改动

### 设置

- 新增 **属性用图片** 开关：关闭后详情的法力/攻击/生命退回灰底细边的小卡片
- 新增 **详情页 3D 效果** 开关：可关掉卡图跟随鼠标的倾斜
