# 更新日志

主站（<https://hstool.pages.dev>）与文档站的改动记录，按日期倒序。日期为实际提交日期（2026 年 11 月）。

## 2026-11-06

### 文档站（新建）

- 上线独立文档站 <https://hstool-docs.pages.dev>，基于 VitePress + Teek 主题，含「指南 / 设置 / 进阶 / 更多」四组页面
- 顶部导航改为下拉式：指南、设置、进阶，以及「更多 → 常见问题 / 更新记录」
- 首页特性区重做为两张卡：**专业卡组**（卡背背景 + 金色渐变 + 能力清单）与 **自由定制**（直传托管、离线可用、开源 MIT）
- 移动端适配：首屏去掉 hero 下方的大块留白、侧边栏改为抽屉 + 遮罩、顶部导航改为点击弹出下拉菜单
- 去掉跟随鼠标移动的聚光灯指示条
- 更新日志重写：按仓库真实提交记录补全 2026-11-01 起的全部改动，不再遗漏

## 2026-11-05

### 卡库

- 新增两种状态提示：**互斥卡**（如雷纳索尔王子与裂魂者阿扎莉娜）显示红色偏色、**份数已满**显示灰黑偏色；传说卡带满 1 张即变灰
- 提示从覆盖层改为滤镜，只作用在卡图上，卡牌边框不再被染红
- 详情页属性支持图形底图（法力水晶 / 剑 / 血滴），数字字号 41px、图标 52px，四项基线逐轮校准到对齐

### 设置

- 新增 **属性用图片** 开关：关闭后退回灰底细边的老式小卡片
- 新增 **详情页 3D 效果** 开关：可关掉卡图跟随鼠标的倾斜
- 新增 **悬停预览滑动** 开关：控制预览框跟随鼠标时的位置过渡，作为「悬停预览」的附属行显示
- 修复三处分割线问题：悬停预览关闭时断线、去边框模式下线条残留、线条颜色被重置成文字色

### 卡组

- 清空卡组去掉动画与金色扫光，改成立即清空
- 移除加卡飞入动画（相关代码一并清理）
- 分享卡组：支持导出图片或链接，链接可反向导入卡组；分享图标改为箭头
- 加载日志搬进设置页的「日志」标签页，可关闭、可清空，不再遮挡中部布局

### 修复

- 奇闻 / 奇利亚斯附属卡不进入卡组列表（服务端卡记录未经过 `normalizeCard`）
- 回归纯前端架构，移除边缘函数索引方案及其产物
