# 全部设置一览

设置分两页：**设置**（功能 / 布局 / 控件三组）与 **关于**，另有**日志**页用于排查加载问题。全部配置存在浏览器 `localStorage`（键名 `hstool-settings`），换浏览器不会同步。

## 功能

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 悬停预览 | 开 | 在组卡器右侧列表悬停卡牌时弹出卡图预览 |
| 悬停预览滑动 | 开 | 预览框跟随鼠标时平滑滑动；关闭后直接跳到新位置（观感等同「减弱动效」）。依附于悬停预览，主开关关闭时本行隐藏 |
| 水晶颜色 | 开 | 法力水晶按稀有度着色；关闭后统一为蓝色 |
| 详情页 3D 效果 | 开 | 鼠标在详情卡面上移动时卡图做轻微 3D 倾斜；关闭后立刻扶正并停止响应 |
| 属性用图片 | 开 | 详情的法力/攻击/生命/耐久用图形底图；关闭后改为灰底细边的小卡片（标签在上、数值在下） |

## 布局

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| MD3 风格 | 开 | Material Design 3 的圆角、阴影与动效；关闭为扁平化 |
| 紧凑布局 | 关 | 收紧行高与间距，一屏多看几张卡 |
| 减弱动效 | 关 | 所有动画/过渡压到近 0 秒，适合低性能设备或晕动敏感 |
| 背景纯色 | 关 | 不显示背景图，改用纯色底 |
| 背景可见度 | 50 | 0–100 滑块，控制背景图的可见强度 |

## 控件

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 卡牌面板透明 | 关 | 面板半透明，透出背景 |
| 搜索栏透明 | 关 | 搜索与筛选区透出背景 |
| 预览图背景透明 | 关 | 卡图加载期间不铺占位底板（注意：关掉后快速划过可能看到短暂空框） |
| 卡牌背景透明 | 关 | 卡面只留描边，透出背景 |
| 去边框去线条 | 关 | 隐藏静态描边与分隔线；开关轨道的描边仍保留（否则控件不可见） |

> 命名约定：凡带「透明」的开关，一律 **ON = 该元素透出背景**，且**默认全部关闭**。

## 日志

设置 → 日志：记录页面加载过程（数据下载、索引构建、卡图回退等），排查「卡牌库加载不出来」时先看这里。可以整体关闭浮层，也可以清空。

## 如何恢复默认

清掉浏览器里本站的 `localStorage` 即可（开发者工具 → Application → Local Storage → 删除 `hstool-settings`），刷新后回到默认值。
